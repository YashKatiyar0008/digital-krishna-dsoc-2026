## 0:40–1:20 — Saathi AI Companion

### Example user input

```text
I am worried about my future and cannot focus on my studies.
```

### Narration

Users can describe a concern naturally in English, Hindi, or Hinglish.

The guidance pipeline identifies the concern category, applies safety
checks, retrieves a relevant teaching when available, and produces a
structured response.

The response may include:

- An empathetic acknowledgement
- Relevant spiritual guidance
- A reviewed scripture reference
- A practical explanation
- Small reflection steps
- A reflection question

### Demonstration guidance

Slowly show the main parts of the guidance response so that judges can
read them.

Do not describe a scripture reference as verified unless the source,
chapter, verse, and reviewed text exist in the project dataset.

## 1:20–1:50 — Scripture Library

### Narration

Digital Krishna provides a structured scripture-learning experience.

Users can explore teachings from the Bhagavad Gita, Ramcharitmanas,
selected Upanishadic teachings, and curated Krishna stories.

The platform separates reviewed source content from AI-generated
interpretation.

This helps prevent generated wording from being presented as an
authentic scripture quotation.

## 2:10–2:40 — Technical Architecture

### Narration

Digital Krishna uses a modular technical architecture.

The frontend is built using React and responsive web technologies.

The backend coordinates request validation, language detection,
concern classification, safety screening, scripture retrieval,
AI-generated interpretation, and response validation.

The project also includes a Qwen-based model-development workflow,
structured datasets, retrieval-augmented generation, multilingual
processing, and private model-serving preparation.

### On-screen architecture

```text
User Input
    ↓
Request Validation
    ↓
Language and Concern Classification
    ↓
Safety Screening
    ↓
Reviewed Scripture Retrieval
    ↓
AI Guidance Generation
    ↓
Source and Response Validation
    ↓
Structured User Response
```

Clearly label prototype or experimental components during the
presentation.
